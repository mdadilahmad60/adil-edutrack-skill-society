ADIL EDUTRACK SKILL SOCIETY — WEBSITE PACKAGE

This is a static, mobile-responsive multi-page website based on the earlier ELITE TUITION PROVIDER website project, rebranded and rebuilt for Adil Edutrack Skill Society.

PAGES
- index.html — Home
- programs.html — Computer, Teachers Training, Professional and Vocational courses
- government-exams.html — Competitive exam preparation
- internships.html — Internships and project-based learning
- certification.html — Certification guidance and placement support
- about.html — About the Society
- admission.html — Admission enquiry form
- contact.html — Contact

GITHUB PAGES
1. Create a NEW GitHub repository. Do not upload over the existing ELITE TUITION PROVIDER repository.
2. Extract this ZIP.
3. Upload the CONTENTS of this folder (index.html, other HTML files, styles.css, script.js and assets folder) to the new repository root.
4. Commit to the main branch.
5. In Settings > Pages, deploy from main branch / root.

FORMS
Forms open WhatsApp with the entered details. They do not store submissions in a database. The WhatsApp number currently uses +91 91224 59605; change WA in script.js and the wa.me links if the society uses another number.
